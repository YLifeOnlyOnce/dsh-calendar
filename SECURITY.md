# Security Policy

## Reporting a vulnerability

Please **do not open a public issue** for security problems. Report privately by emailing the maintainers (see the GitHub repository's About section) with:

- A description of the issue and its impact
- Steps to reproduce
- Affected versions

You'll receive an acknowledgement within a few days and a fix/timeline as soon as possible.

## Scope

This plugin reads DeepSeek Harness session logs and renders usage statistics in the Web GUI. It makes no network calls of its own and sends no data anywhere; the risk surface is the same as any browser-side UI plugin. Reports about the harness core itself should go to the [DeepSeek Harness repository](https://github.com/deepseek-ai/deepseek-harness).
