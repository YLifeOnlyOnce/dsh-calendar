dsh-calendar · 年度热力图
Features

把 DeepSeek 的工作，变成一眼可见的日历

零配置 · 自动读取历史日志 · 跟随主题 · 纯前端动画

🗓️

年度热力图

GitHub 风格 52×7 贡献图，一眼看出哪段时间最忙。

⏱️

任务段时间轴

一次用户输入开启一个任务，5 分钟内的轮次并入 —— 一个任务一根条。

🃏

主界面小卡片

统计、热力图、时间线悬浮在主界面，随意拖拽、折叠、开关。

🖱️

点击直达

点任意区间，直接打开当时的对话会话。

🎨

主题跟随

所有颜色解析自 harness 主题令牌，亮色暗色自动适配。

✨

开箱即用

历史会话启动时自动折叠缓存，上个月的活动打开就有。

安装到 Web profile，重启后打开 设置 → 📅 日程表

$ dsh plugin --profile web add dsh-usage-calendar
